# apps

- `source.json` — źródło aplikacji AltStore (Stremio).
- [`olx-agent/`](olx-agent/) — plugin Claude **olx-zakupy**: asystent zakupów na OLX.pl (wyszukiwanie, ocena zdjęć
  i opisów, porównanie, negocjacje, bezpieczny zakup). Działa w ramach subskrypcji Claude — w Claude Code, Cowork
  i aplikacji desktop — oraz jako CLI na Claude API.

To repozytorium jest też marketplace pluginów Claude:

```text
/plugin install olx-zakupy --marketplace miokki/apps
```
